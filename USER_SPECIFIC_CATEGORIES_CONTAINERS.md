# Исправление логики категорий и контейнеров

## Проблема
Пользователи видели все категории и контейнеры всех пользователей, что нарушало приватность данных.

## Решение
Реализована логика, при которой пользователь видит только:
- Свои личные категории и контейнеры
- Системные (общие) категории и контейнеры

## Изменения в бэкенде

### 1. Контроллер контейнеров (`containers.controller.ts`)
- **Добавлен guard** для метода `findAll()` - теперь требует аутентификации
- **Передача userId** в сервис для фильтрации результатов
- **Исправлены поля JWT** - используется `req.user.userId` вместо `req.user.sub`

### 2. Сервис контейнеров (`containers.service.ts`)
- **Обновлен метод `findAll(userId)`** - теперь принимает userId
- **Фильтрация по автору**:
  ```typescript
  where: [
    { author: { id: userId } }, // Личные контейнеры
    { author: IsNull() }        // Системные контейнеры
  ]
  ```
- **Добавлен импорт `IsNull`** из TypeORM

### 3. Контроллер категорий (`categories.controller.ts`)
- **Исправлены поля JWT** - используется `req.user.userId` вместо `req.user.sub`
- Логика уже была правильной (фильтрация работала)

### 4. Сервис инициализации (`seed.service.ts`)
- **Создан новый сервис** для автоматического создания системных данных
- **Системная категория**: "Без категории" (серый цвет, иконка help-circle)
- **Системный контейнер**: "Общее" (для точек без специальной категоризации)
- **Автоматический запуск** при старте приложения через `OnModuleInit`

### 5. Главный модуль (`app.module.ts`)
- **Добавлен SeedService** в providers
- **Добавлен TypeOrmModule.forFeature** для доступа к репозиториям в SeedService

## Логика работы

### Категории:
- Пользователь видит свои категории + системную "Без категории"
- Может создавать, редактировать и удалять только свои категории
- Системные категории нельзя изменять или удалять

### Контейнеры:
- Пользователь видит свои контейнеры + системный "Общее"
- Может создавать, редактировать и удалять только свои контейнеры
- Системные контейнеры нельзя изменять или удалять

### Системные записи:
- **author = null** - признак системной записи
- Создаются автоматически при первом запуске приложения
- Доступны всем пользователям для использования
- Защищены от изменения и удаления

## Безопасность
- ✅ Пользователи видят только свои данные + системные
- ✅ Нельзя редактировать чужие категории/контейнеры
- ✅ Нельзя удалять чужие категории/контейнеры
- ✅ Системные записи защищены от изменений
- ✅ Все операции требуют аутентификации

## Результат
Теперь при создании точки пользователь увидит:
- Свои личные категории + "Без категории"
- Свои личные контейнеры + "Общее"

Это обеспечивает приватность данных и удобство использования.
