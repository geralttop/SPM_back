# Настройка Drag-n-Drop для вкладок Sidebar

## Что добавлено

1. **Бэкенд:**
   - Поле `sidebarOrder` (JSON) в таблице `users` для хранения порядка вкладок
   - Эндпоинт `PATCH /auth/sidebar-order` для обновления порядка
   - Поле `sidebarOrder` добавлено в ответ `GET /auth/profile`
   - Миграция для добавления поля в БД

2. **Фронтенд:**
   - Drag-n-Drop функциональность с HTML5 API
   - Автоматическая синхронизация порядка с сервером
   - Визуальная обратная связь при перетаскивании (иконка GripVertical)
   - Восстановление порядка из профиля пользователя

## Установка

✅ Миграция уже применена! Поле `sidebarOrder` добавлено в таблицу `users`.

### Запустите бэкенд

```bash
cd SPM_backend
npm run start:dev
```

### Фронтенд готов к использованию

Просто перезагрузите страницу - изменения уже применены.

## Как использовать

1. Наведите курсор на любую вкладку в sidebar
2. Появится иконка с тремя горизонтальными линиями (⋮⋮)
3. Зажмите и перетащите вкладку на новое место
4. Порядок автоматически сохранится на сервере
5. При входе с другого устройства порядок восстановится

## Технические детали

- Порядок хранится как массив ID вкладок: `["feed", "favorites", "profile", ...]`
- При добавлении новых вкладок они автоматически добавляются в конец
- Если пользователь еще не настраивал порядок, используется дефолтный
- Админская вкладка добавляется только для пользователей с ролью `admin`
