# Система жалоб - Резюме реализации

## ✅ Что реализовано

### 1. Базовая функциональность
- **Жалобы на точки** - пользователи могут жаловаться на точки на карте
- **Жалобы на комментарии** - жалобы на комментарии к точкам
- **Жалобы на пользователей** - жалобы на других пользователей
- **5 типов причин жалоб**: спам, неподходящий контент, домогательства, фейк, другое
- **4 статуса жалоб**: ожидает рассмотрения, рассмотрена, решена, отклонена

### 2. Пользовательский функционал
- `POST /reports` - создание жалобы (требует авторизации)
- Валидация: нельзя жаловаться на себя, нельзя подавать повторные жалобы
- Проверка существования объектов жалоб

### 3. Админский функционал
- `GET /admin/reports` - список всех жалоб с фильтрацией и пагинацией
- `GET /admin/reports/:id` - просмотр конкретной жалобы
- `PUT /admin/reports/:id` - обновление статуса жалобы
- `POST /admin/reports/:id/resolve` - обработка жалобы с действиями:
  - **delete** - удалить объект жалобы (точку/комментарий)
  - **block** - заблокировать пользователя
  - **dismiss** - отклонить жалобу
- `DELETE /admin/reports/:id` - удалить жалобу

### 4. Система блокировки пользователей
- `POST /admin/users/:id/block` - заблокировать пользователя
- `POST /admin/users/:id/unblock` - разблокировать пользователя  
- `GET /admin/users/blocked` - список заблокированных пользователей
- Заблокированные пользователи не могут выполнять действия в системе
- Нельзя заблокировать администраторов

### 5. База данных
- **Таблица reports** - хранение всех жалоб с внешними ключами
- **Поля блокировки в users** - isBlocked, blockedAt, blockReason
- **Индексы** для оптимизации запросов по статусу, типу и дате
- **Каскадное удаление** при удалении связанных объектов

### 6. Безопасность
- JWT авторизация для всех действий
- Проверка ролей для админских функций
- Валидация данных через DTO
- Защита от дублирования жалоб
- Guard для блокировки заблокированных пользователей

## 🚀 Как запустить

1. **Запустите PostgreSQL:**
   ```bash
   docker-compose up -d
   ```

2. **Выполните миграции:**
   ```bash
   npm run migration:run
   ```

3. **Запустите сервер:**
   ```bash
   npm run start:dev
   ```

4. **Протестируйте:**
   ```bash
   node test-reports.js
   ```

## 📋 Примеры использования

### Создание жалобы на точку
```bash
curl -X POST http://localhost:3000/reports \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "point",
    "reason": "spam",
    "description": "Спам точка",
    "pointId": "point-uuid"
  }'
```

### Обработка жалобы админом
```bash
curl -X POST http://localhost:3000/admin/reports/1/resolve \
  -H "Authorization: Bearer ADMIN_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "delete",
    "adminNotes": "Точка удалена по жалобе"
  }'
```
